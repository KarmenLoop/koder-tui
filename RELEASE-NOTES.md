# Koder TUI 0.3.0

Koder TUI brings the complete Koder CLI 0.4.12 runtime into an independent terminal workbench. Windows x64, macOS Apple Silicon and Intel archives include Node.js 22.23.3.

The composer stays available during streaming. Ctrl-S steers the active turn, while Esc and Ctrl-C interrupt without exiting. Queue future prompts, reorder them, expand the session Todo with Ctrl-T, and restore conversation and Todo metadata with /undo. The configurable status line includes model, context, workspace and rotating shortcut tips. /help contains 79 entries and Ctrl-P exposes 58 original CLI routes. A transparent refracting loop provides ambient motion.

Installation is per-user and retains an existing CLI command and profile. The full runtime, its business modules, KARMEN LOOP engine, documentation and third-party notices ship in every archive. No model credential or external permission is bundled.

## Verification

Before packaging, 40 workbench tests and 127 targeted CLI tests passed. Real macOS PTY runs passed 10 interaction checks and six supervised-launcher checks. Platform package checks and hosted CI results are listed in release-validation.json.

Windows desktop terminal interaction, ConPTY/IME, native Windows-MCP GUI, live provider and external ACP behavior, cross-device migration, account writes, and accessibility remain unverified unless explicitly recorded in that file. Hosted Windows tests are not a substitute for those device checks. Intel and Apple Silicon packages are separate; no signed desktop application is claimed.

## Behavior to know

Todo undo restores conversation metadata, not completed external effects. Dedicated CLI screens temporarily take over the terminal. External adapters need explicit Todo/undo support. A tight context budget can omit the optional Todo tool for that turn. CLI update/uninstall commands retain their original CLI scope; update this workbench by re-running its installer.
